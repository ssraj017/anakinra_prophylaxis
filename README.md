# anakinra_prophylaxis
Code Repository for the manuscript presenting the results of a phase 2 study of anakinra prophylaxis in patients treated with CD19-CAR-T, titled 'Interleukin-1 Inhibition with Anakinra In CD19 CAR T Therapy for Lymphoma'

.RMD file is a notebook with all the relevant code and functions.R contains the requisite functions used in the main notebook.
